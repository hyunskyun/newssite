# 슬라이드 레이아웃 변형 검토 목록

`npm run gen:slides` 가 만든 파일입니다. 변형 규칙(열 수 · 정렬 · 이미지 위치 · 배경 반전)으로 조합한 결과를 사람이 확인하기 위한 목록입니다.

- 조합 27개 중 16개 채택, 11개 제외
- 전체 레이아웃 102종 (직접 설계 86종 + 변형 16종 + 직접 추가 0종)

## 채택한 변형

| id | 이름 |
| --- | --- |
| cards-2col | 2열 아이콘 카드 |
| cards-3col | 3열 아이콘 카드 |
| cards-3col-invert | 3열 아이콘 카드 · 배경 반전 |
| cards-4col | 4열 아이콘 카드 |
| cards-4col-invert | 4열 아이콘 카드 · 배경 반전 |
| cards-5col | 5열 아이콘 카드 |
| cards-6col | 6열 아이콘 카드 |
| imgcards-2col | 2열 사진 카드 |
| imgcards-3col | 3열 사진 카드 |
| imgcards-4col | 4열 사진 카드 |
| photo-focus | 사진 + 핵심 문장 |
| photo-right-left | 사진 오른쪽 + 문장 왼쪽 정렬 |
| photo-top-left | 사진 위 + 문장 왼쪽 정렬 |
| photo-top-center | 사진 위 + 문장 가운데 정렬 |
| photo-bg-left | 사진 배경 + 문장 왼쪽 정렬 |
| photo-bg-center | 사진 배경 + 문장 가운데 정렬 |

## 제외한 변형

| id | 이름 | 제외 이유 |
| --- | --- | --- |
| cards-2col-invert | 2열 아이콘 카드 · 배경 반전 | 배경 반전은 3·4열만 남김(2열은 색면이 너무 넓고, 5·6열은 카드가 잘게 쪼개져 산만함) |
| cards-5col-invert | 5열 아이콘 카드 · 배경 반전 | 배경 반전은 3·4열만 남김(2열은 색면이 너무 넓고, 5·6열은 카드가 잘게 쪼개져 산만함) |
| cards-6col-invert | 6열 아이콘 카드 · 배경 반전 | 배경 반전은 3·4열만 남김(2열은 색면이 너무 넓고, 5·6열은 카드가 잘게 쪼개져 산만함) |
| imgcards-5col | 5열 사진 카드 | 5열 이상은 사진이 너무 작아 알아보기 어려움 |
| imgcards-6col | 6열 사진 카드 | 5열 이상은 사진이 너무 작아 알아보기 어려움 |
| photo-left-center | 사진 왼쪽 + 문장 가운데 정렬 | 좁은 반쪽 칸에서 가운데 정렬은 줄 길이가 들쭉날쭉해 어색함 |
| photo-left-right | 사진 왼쪽 + 문장 오른쪽 정렬 | 사진과 멀어지는 쪽으로 정렬되어 시선이 끊김 |
| photo-right-center | 사진 오른쪽 + 문장 가운데 정렬 | 좁은 반쪽 칸에서 가운데 정렬은 줄 길이가 들쭉날쭉해 어색함 |
| photo-right-right | 사진 오른쪽 + 문장 오른쪽 정렬 | 오른쪽 정렬 문장은 사진이 왼쪽에 있을 때만 자연스러움 |
| photo-top-right | 사진 위 + 문장 오른쪽 정렬 | 오른쪽 정렬 문장은 사진이 왼쪽에 있을 때만 자연스러움 |
| photo-bg-right | 사진 배경 + 문장 오른쪽 정렬 | 오른쪽 정렬 문장은 사진이 왼쪽에 있을 때만 자연스러움 |
